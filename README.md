Restaurant Billing System

About the Project

Restaurant Billing System is a console-based Java application developed as part of the Syntecxhub Java Programming Internship.

The system allows users to manage restaurant menu items, add items to a customer's bill, remove items, calculate the subtotal, apply GST, and generate a final itemized bill.

Features

- Display restaurant menu
- Add items to bill
- Update item quantity
- Remove items from bill
- Add new menu items
- Remove menu items
- Calculate subtotal
- Calculate 5% GST
- Generate final itemized bill
- Input validation
- Console-based interface

Technologies Used

- Java
- ArrayList
- Classes and Objects
- Methods
- Scanner
- Basic OOP concepts
